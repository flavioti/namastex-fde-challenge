# Rastreabilidade das decisões de design

Histórico de alterações dos documentos de design do AutoSeguro (PRD, RFC, ADR e FDD em `docs/`).

## Para que serve

- Registrar cada mudança de status e cada decisão tomada nos documentos de `docs/`.
- Servir de fonte para as decisões da IA. Antes de propor ou decidir algo de arquitetura ou regra de negócio, consulte este arquivo e os documentos citados aqui. Se a informação não estiver aqui nem nos documentos, pergunte ao usuário em vez de presumir.

## Como manter

- Toda criação, aprovação, aceitação, rejeição ou substituição de documento gera uma linha no registro abaixo.
- Cite o documento com wikilink `[[nome-do-arquivo]]`, sem `.md`. O aviso de pendências verifica se cada documento aparece aqui.
- Não apague linhas antigas. Para corrigir uma decisão, acrescente uma linha nova explicando o motivo.
